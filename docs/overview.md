
# Обзор и ключевые изменения

**v1.1.1:** восстановлен/дополнен функционал для ОС Linux (не тестировалось)

**v1.1.0:** подключение нескольких устройств и HOT-обновление.

## Возможности

- Проект на JavaScript — быстрый встроенный веб-сервер.
- Весь текст вынесен в `src/utils/consts.js` — легко перевести/переименовать.
- Туннельный проброс веб-интерфейса через личный сервер на внешний URL.
- Ограничение сессий использования ПК и интервалов между ними.
- Запланированное отключение ПК.
- Прерывание работы программы через веб-интерфейс.
- Автоматическое переконфигурирование `frpc` при перезагрузках ВМ и перезаписи конфигов.

## Особенности

- **Полная автозагрузка** — через Windows Service (стартует до входа пользователя)
  или systemd-сервис на Linux.
- **Резервная автозагрузка** — ярлык в Startup (Windows, если служба не работает).
- **Удалённое управление** — TCP-сокет.
- **Логирование** — все действия пишутся в файл.
- **Состояние сохраняется** — лимиты и расписание переживают перезагрузку.
- **Предупреждения** — за 15, 5 и 1 минуту до блокировки.
