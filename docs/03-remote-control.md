# Удалённое управление

## Локальная сеть (веб)

Откройте в браузере: `http://<TARGET_IP>:5000`

## TCP-сокет (telnet и аналоги)

Подключение к порту `9999`. Допустимые команды:

| Команда | Действие |
| --- | --- |
| `END_BREAK` | Принудительно завершить перерыв |
| `SET_BREAK_DURATION` | Установить время отдыха между сессиями |
| `HANDLE_UNLOCK` | Разблокировать ПК (если нет пароля) |
| `SET_SESSION_LIMIT` | Установить лимит сессии |
| `CAN_UNLOCK` | Проверка возможности разблокировки |
| `LOCK` | Заблокировать ПК |
| `SHUTDOWN` | Выключить ПК через минуту |
| `SHUTDOWN_NOW` | Выключить ПК через 10 секунд |
| `CANCEL_SHUTDOWN` | Отмена отложенного выключения |
| `GET_NAME` | Имя ПК |
| `GET_SESSION_TIME` | Время текущей сессии |
| `GET_USAGE_TIME` | Суточное время использования |
| `GET_CURRENT_USER` | Текущий пользователь |
| `GET_STATUS` | Состояние блокировки |
| `GET_LOCK_TIMES` | Время отложенной блокировки |
| `GET_TIME_REMAINING` | Время до блокировки |
| `GET_USAGE_LIMIT` | Дневной лимит |
| `GET_SESSION_LIMIT` | Лимит сессии |
| `RESET_USAGE` | Сбросить суточное время |
| `RESET_SESSION` | Сбросить время текущей сессии |
| `GET_SESSION_BREAK` | Время отдыха между сессиями |
| `GET_SHUTDOWN_TIME` | Время отложенного выключения |
| `GET_SHUTDOWN_ABORT` | Была ли отмена отложенного выключения |
| `MESSAGE:<-text->` | Отправить сообщение |
| `SET_LIMIT:<-minutes->` | Дневной лимит |
| `ADD_LOCK_TIME:HH:MM` | Добавить отложенную блокировку |
| `EXTEND_TIME:<-minutes->` | Увеличить время использования |
| `CLEAR_USAGE_LIMIT` | Удалить дневной лимит |
| `CLEAR_LOCK_TIMES` | Удалить отложенные блокировки |
| `CLEAR_ALL` | Удалить все лимиты и отложенные действия |
| `HELP` | Список команд |
